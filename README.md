## The confession

## How it works

`main.ts` (Node 22, standard library only, no network, no randomness) writes
exactly one line — the confession above, 97 characters, no trailing newline —
to `/output/entry.txt`. The same line is produced on every run, so the output
is fully deterministic.

Run it with:

```sh
node main.ts
```
